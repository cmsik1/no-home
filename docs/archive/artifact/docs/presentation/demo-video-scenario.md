## 촬영 전 준비

- 백엔드, 프론트엔드, MySQL이 모두 실행 중인지 확인한다.
- 프론트엔드 접속 주소와 백엔드 health 응답을 확인한다.
- Kakao 지도 키, 공공데이터 키, AI/GMS 키가 설정되어 있는지 확인한다.
- 데모 계정으로 사용할 이메일, 이름, 비밀번호를 미리 정한다.
  - 예시: `demo-user@nohome.local`
  - 영상에 노출되어도 되는 값만 사용한다.
- 같은 이메일로 이미 가입되어 있으면 다른 데모 이메일을 사용한다.
- 관리자 계정 이메일과 비밀번호를 미리 준비한다.
  - 관리자 계정은 공지 추가와 회원 검색 권한이 있는 계정이어야 한다.
  - 회원 검색 장면에서는 앞에서 가입한 데모 회원 이메일을 검색어로 사용한다.
- 수동 검색용 조건은 미리 정하되, 실제 조회는 촬영 중 처음 수행한다.
  - 사전 조회를 하면 DB에 캐시되어 첫 검색 장면의 속도와 데이터 적재 흐름이 달라질 수 있다.
  - 강남구 2015년 1월-2015년 2월 매매
  - 강남구 2015년 1월-2015년 2월 월세
  - 강남구 역삼동
- 챗봇 답변형 질문도 촬영 전에 같은 조건으로 미리 실행하지 않는다.
  - 사전 실행 시 해당 지역/월 데이터가 캐시될 수 있으므로, 촬영용 질문은 촬영 때 처음 입력한다.
  - `종로구 2015년 1월 평균 거래가 알려줘`
- 챗봇 실행형 명령도 같은 지역/월 조건으로 사전 검색하지 않는다.
  - 기능 자체 점검이 필요하면 촬영용 조건과 다른 지역/월로 별도 테스트한다.
  - `강남구 2024년 3월 매매가 검색해줘`
  - `3페이지로 이동해줘`
  - `2번째 항목 선택해줘`

- [ ] 데모 계정 이메일이 중복되지 않는다.
- [ ] 초기 화면이 검색창과 지도 화면 중심으로 보인다.
- [ ] 회원가입 성공 메시지가 정상 한글로 보인다.
- [ ] 일반 회원 로그인 후 상단 계정 상태가 바뀐다.
- [ ] 일반 회원 로그인 상태에서 공지사항 아이콘으로 공지 목록에 진입한다.
- [ ] 일반 회원 로그아웃 후 상단 계정 상태가 바뀐다.
- [ ] 관리자 계정으로 로그인한다.
- [ ] 관리자 권한으로 공지사항을 추가한다.
- [ ] 회원 검색에서 앞에서 가입한 데모 회원 계정이 조회된다.
- [ ] 촬영용 검색 조건을 사전에 같은 조건으로 조회하지 않았다.
- [ ] 강남구 2015년 1월-2015년 2월 매매 검색 결과가 촬영 중 처음 조회로 나온다.
- [ ] 강남구 역삼동 조건 적용 시 저장된 DB 데이터를 우선 활용한다는 설명이 들어간다.
- [ ] 매매 검색에서 가격순 정렬을 보여준다.
- [ ] 매매 검색에서 전용면적 넓은순 정렬을 보여준다.
- [ ] 강남구 2015년 1월-2015년 2월 월세 검색 결과를 보여준다.
- [ ] 월세 검색 결과에서 보증금과 월세가 함께 보인다.
- [ ] 보증금 슬라이더로 가격 범위를 설정해 검색한다.
- [ ] 월세 슬라이더로 가격 범위를 설정해 검색한다.
- [ ] 역삼동 조건 적용 시 결과가 좁혀진다.
- [ ] 챗봇 패널이 로그인 상태에서 정상 동작한다.
- [ ] `종로구 2015년 1월 평균 거래가 알려줘` 질문은 촬영 전에 같은 조건으로 실행하지 않았다.
- [ ] `종로구 2015년 1월 평균 거래가 알려줘` 질문으로 텍스트 답변이 반환된다.

## 제외 기준

- 전체 영상이 길어지면 회원가입 입력 과정, 로딩, 챗봇 대기 시간을 우선 컷하거나 빠르게감기로 처리한다.
- 회원가입 입력이 길어지면 입력 중간을 컷하고 가입 완료 직전부터 이어 붙인다.
- 공지 추가 장면에서는 제목과 내용을 짧게 입력하고, 수정/삭제는 보여주지 않는다.
- 챗봇 응답 대기가 길면 로딩 장면을 1-2초만 남긴다.
- 지도 마커 로딩이 늦거나 외부 지도 오류가 보이면 해당 컷은 재촬영한다.
