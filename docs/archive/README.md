# Archive

이 폴더는 M1 프로젝트 구조 정리 이전에 `Artifact`와 `Backend/docs`에 있던 자료를 보존한다.

- `artifact/`: 기획 문서, 다이어그램, 발표 자료, 산출물과 과거 AI 작업 기록
- `backend/`: Backend 기능별 작업 기록, 보고서와 트러블슈팅 문서

Archive 문서의 본문과 첨부 파일은 역사 기록 보존을 위해 이동 당시 상태를 유지한다. 따라서 본문에 적힌 소스 경로나 링크가 현재 프로젝트 구조와 다를 수 있으며, 현재 기준은 상위 [문서 안내](../README.md)를 따른다.
