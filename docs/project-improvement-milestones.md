# 프로젝트 개선 마일스톤

## M1. 프로젝트 구조 정리

- `BackendAtlas` 삭제
- `Artifact`와 `Backend/docs`를 루트 `docs`로 통합
- 깨진 문서 링크와 README 정리

## M2. 프로젝트 파이프라인 문서 작성

- 서버 실행부터 사용자 요청·응답까지의 전체 흐름 설명
- Maven Wrapper와 생성 파일이 만들어지는 과정 설명
- 백엔드 면접 질문에 대응할 수 있는 핵심 개념과 설계 근거 정리

## M3. 소스코드 주석 보강

- Backend와 Frontend의 핵심 클래스·함수 책임 설명
- 데이터가 이동하고 변환되는 과정 설명
- 중요한 비즈니스 규칙과 기술적 결정에만 주석 추가

## M4. 리팩터링 후보 검토

- 주석 작업 중 발견한 구조적 문제 정리
- 영향도와 우선순위 평가
- 사용자 승인 후 리팩터링 세부 계획 수립

## M5. 전체 검증

- Backend·Frontend 테스트 및 빌드
- 문서 링크와 프로젝트 실행 방법 확인
- 주석·문서가 실제 코드 동작과 일치하는지 최종 검토
