# NOHOME-3 문서 통합 및 Archive 구성

분산된 과거 산출물과 Backend 개발 기록을 루트 `docs/archive` 아래로 통합한다.

현재 기준 문서와 과거 기록을 폴더로 구분하고, 파일 내용과 바이너리 파일명은 유지한다.

## 결과

- `Artifact`의 89개 파일을 `docs/archive/artifact`로 이동했다.
- `Backend/docs`의 44개 파일을 `docs/archive/backend`로 이동했다.
- Markdown 파일명 8개와 과거 `AGENTS.md` 이름을 정책에 맞게 변경했다.
- 이동 전후 133개 파일의 SHA-256이 모두 일치했다.
