# NOHOME-8 Frontend 핵심 소스 주석 보강

## 목적

Frontend를 처음 읽는 개발자가 사용자 입력과 화면 상태가 hook과 service를 거쳐 Backend API로 이동하고, 응답이 다시 화면 모델로 변환되는 흐름을 소스에서 이해할 수 있게 한다.

## 결과

- 테스트를 제외한 운영 JavaScript·JSX 파일 53개를 모두 분류·검토했다.
- 앱 조율, 검색·가격 범위·지도, 회원·관심 지역·공지, AI 대화와 API 변환을 담당하는 핵심 29개 파일에 함수 설명을 보강했다.
- 단순 표시 컴포넌트, 상수와 자명한 위임 함수에는 주석을 강제하지 않았다.
- 공개 API 계약, 함수 시그니처와 화면 동작은 변경하지 않았다.

## 검증

- Node 단위 테스트: 52개 통과
- Vitest 컴포넌트 테스트: 4개 통과
- Vite production build: 성공
- Markdown 링크 검사와 `git diff --check`: 통과

로컬 Node 실행 환경이 없어 Docker의 Node 20 이미지로 검증했다. 설치 시 기존 의존성에서 보안 취약점 5개가 보고됐으며, 의존성 갱신은 별도 리팩터링 검토 대상으로 남겼다.
