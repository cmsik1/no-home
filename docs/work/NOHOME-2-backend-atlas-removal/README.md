# NOHOME-2 BackendAtlas 제거

프로젝트에서 더 이상 사용하는 기능이 아닌 `BackendAtlas`와 현재 사용 안내의 관련 링크를 제거한다.

Backend와 Frontend 운영 소스는 변경하지 않는다. Jira 및 마일스톤 문서에는 작업 이력을 보존한다.

## 결과

- `BackendAtlas` 디렉터리와 루트 README의 현재 사용 안내를 제거했다.
- Backend와 Frontend 운영 소스 및 사용자의 `.gitignore` 변경은 건드리지 않았다.
- 사용자가 최종 폴더 구조와 README를 확인하고 작업 종료를 승인했다.
