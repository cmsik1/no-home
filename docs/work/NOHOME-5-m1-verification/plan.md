# NOHOME-5 세부 계획

## 범위

- M1 삭제 대상과 이전 문서 경로의 부재를 확인한다.
- 이동된 문서 수와 Git blob 동일성을 확인한다.
- 현재 문서 링크와 대표 이미지 렌더링을 확인한다.
- M1 기준 커밋 이후 운영 소스, API와 DB schema가 바뀌지 않았는지 확인한다.
- 사용자 소유 `.gitignore` 변경이 보존됐는지 확인한다.

## 완료 기준

- [x] 삭제 대상과 이전 문서 디렉터리가 존재하지 않는다.
- [x] 문서 133개의 이동 전후 Git blob이 모두 동일하다.
- [x] 현재 문서의 로컬 링크 검사가 통과한다.
- [x] Backend·Frontend 운영 소스, API와 DB schema 변경이 없다.
- [x] `.gitignore`의 사용자 변경이 보존된다.
- [x] 문서 구조와 대표 이미지가 실제로 열리는 것을 확인한다.
