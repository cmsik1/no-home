# NOHOME-6 세부 계획

## 범위

- Compose와 Backend·Frontend 기동 설정을 실제 파일과 대조한다.
- 공통 HTTP 흐름과 주택 검색, 로그인, AI 요청의 대표 파이프라인을 추적한다.
- 데이터 변환, 트랜잭션, 예외 처리와 DB schema 관계를 설명한다.
- Maven Wrapper와 build·runtime 생성 파일의 생성 주체를 설명한다.
- 구조와 관련된 면접 질문, 설계 근거와 확장 시 트레이드오프를 정리한다.

## 제외 범위

- 운영 소스와 기능은 변경하지 않는다.
- Maven Wrapper와 생성 파일에는 개별 주석을 달지 않는다.

## 검증

- 문서에서 참조한 모든 저장소 파일 경로가 존재해야 한다.
- 현재 Markdown 링크 검사가 통과해야 한다.
- 문서 설명과 endpoint, 설정, dependency, schema가 실제 소스와 일치해야 한다.
- Backend와 Frontend 운영 소스 변경이 없어야 한다.

## 완료 기준

- [x] 서버 기동부터 응답 렌더링까지 전체 흐름이 설명된다.
- [x] 대표 세 기능의 입력·변환·저장·응답 경로가 설명된다.
- [x] Maven Wrapper와 주요 생성 파일을 재생성할 수 있는 수준으로 설명한다.
- [x] 핵심 백엔드 면접 질문과 현재 구조의 트레이드오프가 포함된다.
