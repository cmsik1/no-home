NoHome 시연 진행 대본

1. 메인 화면

NoHome의 초기 화면입니다.
화면은 실거래가를 검색하는 검색창과, 검색 결과를 확인할 수 있는 지도 중심으로 구성되어 있습니다.
사용자는 지역, 기간, 거래 유형을 기준으로 아파트 실거래가를 조회하고, 결과를 지도와 목록에서 함께 확인할 수 있습니다.

2. 회원가입 진행

먼저 데모 계정으로 회원가입을 진행하겠습니다.
이메일, 이름, 비밀번호 등 필요한 정보를 입력하고 회원가입을 완료합니다.
비밀번호 입력 과정은 촬영에서는 길게 보여주지 않고, 입력 완료 상태 위주로 진행합니다.

3. 로그인 진행

회원가입이 완료되면 방금 만든 계정으로 로그인합니다.
로그인에 성공하면 상단 계정 상태가 바뀌는 것을 확인할 수 있습니다.
이후에는 로그인 사용자에게 제공되는 AI 챗봇 기능까지 함께 사용할 수 있습니다.

4. 공지사항 진입

상단 헤더의 공지사항 아이콘을 클릭합니다.
공지사항 목록 화면으로 이동하면 등록된 공지 내용을 확인할 수 있습니다.
이 장면에서는 일반 사용자가 공지사항을 확인하는 흐름을 보여줍니다.

5. 일반 회원 로그아웃

이제 관리자 기능을 보여주기 위해 일반 회원 계정에서 로그아웃합니다.
로그아웃 후 상단 계정 표시가 비로그인 상태로 바뀌는 것을 확인합니다.

6. 관리자 계정 로그인

준비된 관리자 계정으로 다시 로그인합니다.
관리자 계정에서는 일반 회원과 달리 공지 작성과 회원 검색 기능을 사용할 수 있습니다.
로그인 후 관리자 전용 메뉴가 보이는지 확인합니다.

7. 관리자 공지 추가

공지사항 화면에서 새 공지를 추가합니다.
제목과 내용을 짧게 입력하고 등록합니다.
등록이 완료되면 방금 작성한 공지가 목록에 반영되는 것을 확인합니다.

8. 관리자 회원 검색

회원 검색 화면으로 이동합니다.
앞에서 회원가입한 데모 회원 이메일을 검색어로 입력합니다.
검색 결과에 해당 회원 계정이 조회되는 것을 보여줍니다.
이 장면은 관리자만 사용할 수 있는 회원 관리 기능을 보여주는 부분입니다.

9. 매매 검색 조건 설정

이제 핵심 기능인 실거래가 검색을 보여주겠습니다.
검색 화면으로 돌아가서 서울시 강남구를 선택합니다.
거래 기간은 2015년 1월부터 2015년 2월까지로 설정하고, 거래 유형은 매매로 선택합니다.
동 조건은 전체동으로 둔 상태에서 검색을 실행합니다.

10. 매매 검색 결과 확인

검색 결과가 나오면 왼쪽에는 실거래가 목록이 표시되고, 오른쪽 지도에는 결과 위치가 마커로 표시됩니다.
사용자는 거래 목록과 지도 위치를 함께 보면서 강남구 전체의 거래 흐름을 확인할 수 있습니다.
첫 조회 시간이 길면 촬영본에서는 빠르게감기나 컷 편집으로 처리합니다.

11. 역삼동으로 검색 범위 좁히기

이번에는 강남구 전체동에서 역삼동으로 조건을 좁혀 다시 검색합니다.
앞에서 한 번 조회한 강남구 데이터는 DB에 저장되어 있기 때문에, 같은 구간 안에서 다시 좁혀 볼 때는 저장된 데이터를 우선 활용할 수 있습니다.
그래서 처음 조회보다 더 빠르게 결과를 불러오는 흐름을 보여줄 수 있습니다.

12. 가격순 정렬

정렬 옵션을 가격순으로 변경합니다.
가격순 정렬을 적용하면 거래금액 기준으로 결과를 다시 볼 수 있습니다.
같은 검색 결과라도 사용자가 중요하게 보는 기준에 따라 비교할 수 있다는 점을 보여줍니다.

13. 전용면적 넓은순 정렬

이번에는 전용면적이 넓은 순서로 정렬합니다.
가격뿐 아니라 면적 기준으로도 매물을 비교할 수 있습니다.
첫 번째 결과의 면적 값이 화면에 보이도록 잠시 멈춰 줍니다.

14. 월세 검색 조건 설정

다음은 월세 검색입니다.
거래 유형을 월세로 변경하고, 다시 서울시 강남구 2015년 1월부터 2015년 2월까지 전체동 조건으로 검색합니다.
월세 검색에서는 보증금과 월세 금액을 함께 확인하는 것이 중요합니다.

15. 월세 검색 결과 확인

월세 검색 결과에서는 각 결과 카드에 보증금과 월세가 함께 표시됩니다.
사용자는 초기 비용인 보증금과 매달 부담해야 하는 월세를 동시에 비교할 수 있습니다.
결과 카드의 보증금과 월세 정보가 잘 보이도록 촬영합니다.

16. 보증금 슬라이더 검색

보증금 슬라이더를 조정해서 원하는 보증금 범위를 설정합니다.
그 상태로 다시 검색하면 보증금 조건이 적용된 결과만 확인할 수 있습니다.
슬라이더 조작은 짧게 보여주고 결과가 갱신되는 장면을 남깁니다.

17. 월세 슬라이더 검색

이어서 월세 슬라이더를 조정합니다.
매달 부담 가능한 월세 범위를 설정하고 검색합니다.
월세 검색에서는 보증금과 월세를 각각 조정해 조건에 맞는 거래를 찾을 수 있습니다.

18. 챗봇 열기

다음은 로그인 후 사용할 수 있는 AI 챗봇입니다.
화면의 챗봇 버튼을 클릭해 NoHome AI 도우미 패널을 엽니다.
먼저 실거래가 질문에 대한 답변을 받아보겠습니다.

19. 챗봇 답변형 질문

챗봇 입력창에 종로구 2015년 1월 평균 거래가 알려줘 라고 입력합니다.
AI는 해당 조건의 데이터를 조회하고, 평균 거래가를 텍스트 답변으로 요약해 줍니다.
이 장면에서는 챗봇으로 실거래가 질문에 대한 답변을 바로 얻을 수 있다는 점을 보여줍니다.

20. 챗봇 검색 실행 요청

이어서 같은 챗봇에 실제 검색 실행을 요청합니다.
강남구 2024년 3월 매매가 검색해줘 라고 입력합니다.
AI가 지역, 거래월, 거래 유형을 해석하고 검색 조건을 화면에 적용합니다.
사용자가 직접 폼을 조작하지 않아도 검색 화면이 실제 결과로 바뀌는 것을 보여줍니다.

21. 챗봇 페이지 이동 요청

검색 결과가 표시되면 챗봇에 3페이지로 이동해줘 라고 입력합니다.
현재 검색 결과를 기준으로 페이지 이동 명령이 실행됩니다.
페이지 번호가 바뀌는 장면이 보이도록 잠시 멈춥니다.

22. 챗봇 항목 선택 요청

마지막으로 챗봇에 2번째 항목 선택해줘 라고 입력합니다.
AI가 현재 페이지의 2번째 결과를 선택합니다.
선택된 카드나 지도 포커스가 화면에서 확인되도록 보여줍니다.
챗봇으로 답변을 얻는 것뿐 아니라 검색, 페이지 이동, 항목 선택까지 이어서 실행할 수 있다는 점을 보여주는 장면입니다.

23. 마무리

정리하면 NoHome은 공공데이터 기반 실거래가 검색, 회원 기능, 관리자 기능, 그리고 화면을 직접 조작하는 AI 챗봇을 하나의 흐름으로 제공합니다.
사용자는 복잡한 공공데이터를 직접 다루지 않아도, 조건 검색과 AI 도움을 통해 원하는 실거래가 정보를 더 쉽게 탐색할 수 있습니다.
